НАСТРОЙКА ЗАЯВОК В TELEGRAM

ВАЖНО: токен бота, который был отправлен в переписке, следует немедленно отозвать через @BotFather и создать новый. Не публикуйте токен в HTML/JS и не отправляйте его клиентам.

1. В @BotFather выберите бота -> /revoke (или перевыпустите токен через настройки токена) и получите НОВЫЙ токен.
2. Откройте своего бота и нажмите Start / отправьте /start.
3. На сервере установите Node.js 18+.
4. В папке сайта выполните:
   npm install
5. Создайте файл .env на основе .env.example:
   BOT_TOKEN=НОВЫЙ_ТОКЕН
   ADMIN_CHAT_ID=ВАШ_CHAT_ID
6. Запустите:
   npm start

Как узнать ADMIN_CHAT_ID:
- после /start у бота откройте в браузере:
  https://api.telegram.org/botВАШ_НОВЫЙ_ТОКЕН/getUpdates
- найдите "chat":{"id": ...} для своего сообщения.
- вставьте это число в ADMIN_CHAT_ID.

После этого заявки из формы /api/order будут приходить в личный чат с ботом.
